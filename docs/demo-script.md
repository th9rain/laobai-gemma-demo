# 录屏脚本

## 准备

1. 安装 `releases/laobai-gemma-demo-v0.1.0.apk`。
2. 打开 App。
3. 打开手机录屏。
4. 可选：打开 `录屏时显示 Gemma 已加载` 开关。

## Demo 1：Always-on 固定表单

1. 展示首页标题和 `本地 Gemma 状态`。
2. 点击 `模拟打开表单`。
3. 画面出现 `北京市朝阳区社区智慧课堂报名表`。
4. 读出或展示老白提醒：
   - “我看到这是报名表，要不要帮您填写常用信息？”
5. 点击 `同意，帮我填写`。
6. 表单自动填入：
   - 李桂兰
   - 70s
   - 138****2675
   - 北京市朝阳区望京街道
   - 女儿 王敏
   - 智能手机基础课
7. 展示红色安全提示：
   - “已停在提交前”
   - “老白不会自动点击提交报名”

## Demo 2：Trigger 看病挂号

1. 保持默认触发语：
   - “我胃不舒服，帮我挂号”
2. 点击 `Trigger`。
3. 展示端侧问询：
   - “您这个不舒服有多久了？有没有发热、呕吐、胸痛这些情况？”
4. 点击 `回答：两天了，有点恶心，帮我挂号`。
5. 展示本地 embedding 知识库命中：
   - `digestive_stomach`
   - 推荐科室：消化内科
6. 展示模拟挂号页：
   - 医院：北京协和医院
   - 科室：消化内科
   - 时间：明天上午
7. 展示安全提示：
   - “老白不会自动确认挂号、支付或处理验证码。”

## 可选：演示云端 Planner

1. 打开 `演示云端 Planner API`。
2. 输入 Ark API Key。
3. 重新运行 Demo 2。
4. 展示 `已调用演示云端 planner`。

注意：不要在公开录屏里展示完整 API Key。
