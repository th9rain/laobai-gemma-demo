# 录屏脚本

## 准备

1. 安装 `releases/laobai-gemma-demo-v0.2.0.apk`。
2. 打开 App。
3. 点击 `去系统设置启用`，在系统无障碍设置中启用 `老白 Agent 手机操作服务`。
4. 回到 App，点击 `刷新`，确认首页显示 `无障碍服务：已开启`。
5. 开始手机录屏。

## Demo 1：Always-on 自动填表

1. 在首页点击 `Demo 1：Always-on 自动填表`。
2. 展示表单标题：`北京市朝阳区社区智慧课堂报名表`。
3. 说明：老白在端侧识别到固定报名表模板。
4. 等待 1-2 秒，输入框会自动填入：
   - 李桂兰
   - 70s
   - 138****2675
   - 北京市朝阳区望京街道
   - 女儿 王敏
   - 智能手机基础课
5. 展示状态提示：老白已经停在 `提交报名` 前。
6. 讲解重点：主动识别、本地记忆、自动填写、提交前安全停止。

## Demo 2：Trigger 看病挂号

1. 回到首页。
2. 可选：开启 `Ark 云端 planner 替身` 并输入 API Key。公开录屏不要展示完整 Key。
3. 点击 `Demo 2：Trigger 看病挂号`。
4. 展示触发语：`我胃不舒服，帮我挂号`。
5. 老白自动点击 `开始问询`。
6. 页面显示问询：`您这个不舒服有多久了？有没有发热、呕吐、胸痛这些情况？`
7. 老白自动点击演示回答：`两天了，有点恶心，帮我挂号`。
8. 老白填写挂号页：
   - 医院：北京协和医院
   - 科室：消化内科
   - 时间：明天上午
   - 材料：身份证、医保卡、既往病历
9. 展示状态提示：老白已经停在 `确认挂号 / 支付 / 验证码` 前。
10. 讲解重点：用户触发、本地知识库检索、可选云端 planner、端侧执行、安全停止。

## 讲解词建议

```text
老白不是替老人直接做危险决定，而是帮老人理解页面、填写低风险信息、完成重复操作。
涉及提交、支付、验证码、授权时，它必须停下来，让老人或家人确认。
```

```text
这版 APK 已经用 Android 无障碍服务操作真实控件。
云端 planner 只拿到脱敏摘要，不拿原始截图、身份证、完整手机号或验证码。
```
